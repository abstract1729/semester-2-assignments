## IISc MTech AI - Even Semester Assignments

This repository contains assignment descriptions, problem statements, and fully executable source code for the **Even Semester** courses of the Master of Technology (MTech) in Artificial Intelligence program at the **Indian Institute of Science (IISc), Bengaluru**.

### 📌 Repository Overview

This repository serves as a clean code archive for core and elective AI courses completed during the even semester. 

* **Included:** Complete problem descriptions, assignment questions, and all source codes (`.py`, `.ipynb`, etc.) required to execute the solutions. It also includes the resulting reports submitted for the corresponding assignments.
* **Excluded:** Due to storage constraints and repository cleanliness, **model checkpoints** (e.g., `.pt`, `.pkl`, `.h5` files) and **resulting plots/output artifacts** are **not pushed** to this repository. You can generate these artifacts locally by running the provided implementation scripts.

---

### 📚 Courses Covered

The repository is structured logically by courses. Each course folder contains subdirectories for individual assignments with dedicated local descriptions detailing specific implementation steps and prerequisites. Following courses are covered here: 

- E9 246: Advanced Image Processing
- E9 216: Computer Vision
- DS 207: Intro to NLP (Natural Language Processing)
- E1 213: Pattern Recognition and Neural Networks (PRNN)
